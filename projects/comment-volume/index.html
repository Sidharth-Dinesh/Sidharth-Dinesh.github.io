Facebook Comment-Volume Prediction

Comparing four regression models to predict how many comments a Facebook post will receive.

Tools: Python, scikit-learn, TensorFlow, PCA

Overview

This project examined whether a Facebook post’s attributes and previous activity could predict the number of comments it would receive in a future time window. Four regression approaches were compared on the same prediction task.

Approach

  • Evaluated Lasso, gradient boosting, random forest, and neural networks for comment prediction.
  • Scaled input features and applied PCA to reduce the prediction inputs to four components.
  • Compared prediction error and evaluation time across five variants of Facebook activity data.

Implementation

The experiments covered five variants of the Facebook Comment Volume dataset. Feature scaling and PCA reduced the inputs to four principal components before fitting Lasso, gradient boosting, random forest, and neural-network models. Evaluation compared prediction errors and processing time.

Reflections

Considering error alongside evaluation time provided a clearer comparison than accuracy alone. The analysis focused on the volume of comments, with no attempt to interpret their sentiment or content.
