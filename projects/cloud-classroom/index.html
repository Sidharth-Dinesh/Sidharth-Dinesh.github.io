Student Recognition from Classroom Videos

Recognizing students in uploaded classroom videos and looking up their academic records.

Tools: Python, AWS Lambda, S3, DynamoDB, Docker, OpenFaaS

Overview

The application turns uploaded classroom videos into student names and matching academic records. A video upload starts face recognition, followed by a DynamoDB lookup and a CSV file containing the results.

Approach

  • Implemented Python handlers for video recognition on AWS Lambda and OpenFaaS.
  • Queried DynamoDB for recognized students and generated CSV results for storage in Amazon S3.
  • Tested service integration and output correctness with a workload of 100 simultaneous uploads.

Implementation

Python handlers connected video processing to student-record lookups and CSV output. The AWS version used Lambda and S3, while a second version ran OpenFaaS functions on a local Kubernetes cluster. The implementation work also included integration testing and documentation. Face recognition relied on an existing library.

Reflections

Testing followed the full path from uploaded video to saved result. The workload of 100 simultaneous uploads checked how the services worked together and whether the expected output files were produced.
